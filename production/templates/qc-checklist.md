# QC checklist — The Human Story

Mark each: PASS / FAIL (with issue #) / N/A.

## Script
- [ ] Every factual claim matches the research notes / a reputable source
- [ ] Dates, names, places and numbers correct; estimates labelled; debates acknowledged
- [ ] No single-cause oversimplification; causes vs. triggers distinguished
- [ ] No invented quotations
- [ ] British spelling and grammar
- [ ] Hook in first 15 s; clear structure; memorable ending
- [ ] Tone: respectful and non-comic around atrocities and civilian suffering
- [ ] Word count fits each time window (~140–150 wpm planning rate)

## Visuals
- [ ] Style matches `production/characters/style-reference.jpg` (heads, outlines, limbs, colours)
- [ ] Every shot has purposeful movement; no slideshow stretches
- [ ] On-screen text readable on mobile, correct spelling/dates, not over faces or captions
- [ ] Historical figures labelled; fictional characters not presented as real
- [ ] Maps accurate for the date shown
- [ ] No blank, missing or glitched frames; transitions smooth

## Audio
- [ ] Narration complete, clear, consistent voice, correct pronunciation
- [ ] Music under narration; no clipping (≤ −1 dBTP); programme ≈ −14 LUFS
- [ ] No unexplained silence; SFX appropriate (none comic near tragedy)

## Subtitles & technical
- [ ] SRT synced (± 0.25 s), ≤ 2 lines, ≤ 42 chars/line
- [ ] Duration exact; 1920×1080; 30 fps; H.264 + AAC; plays start to finish
- [ ] Chapters match the edit; licences recorded for any third-party asset

## Report format
| # | Severity | Location | Issue | Fix | Responsible agent |
|---|---|---|---|---|---|

Verdict: APPROVED / APPROVED WITH MINOR FIXES / CHANGES REQUIRED / REJECTED
